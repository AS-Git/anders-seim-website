## Zielseite
- **Art:** Landing Page (Homepage), erweiterbar zur vollständigen Website mit Unterseiten
- **Zweck:** SEA-Kampagne für andersundseim.de — Leads / Anfragen generieren
- **Primäre Call-to-Action:** Kontakt aufnehmen / Anfrage stellen
- **URL / Domain:** andersundseim.de
- **Sprache:** Deutsch

## Zielgruppe
- **Wer:** Kleine und mittelständische Unternehmen in Deutschland, Österreich und der Schweiz
- **Bedürfnis:** Online sichtbar werden, mehr qualifizierte Anfragen erhalten
- **Tonalität:** Professionell, direkt, vertrauenswürdig — nicht zu technisch
- **Sprache der Ansprache:** Du oder Sie → TBD

## Geplante Sektionen
> Reihenfolge der One-Pager-Abschnitte (oben nach unten).

1. **Header / Navigation** – Logo + Anker-Links
2. **Hero** – Headline, Subline, Haupt-CTA
3. **Leistungen** – Webdesign, SEO, GEO, Online-Marketing
4. **Vorteile / USPs** – 100 % Weiterempfehlung (ProvenExpert), Erfahrung, Transparenz
5. **Social Proof** – Kundenstimmen / Bewertungen
6. **Kontakt / CTA** – Kontaktformular oder Mailto
7. **Footer** – Impressum, Datenschutz

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Sprache:** TypeScript
- **Styling:** Tailwind CSS v4
- **Komponenten:** shadcn/ui
- **Icons:** Lucide React
- **Forms:** react-hook-form + Zod
- **CMS:** Kein Backend zum Start — Inhalte in `src/content/`. CMS (Sanity o. Ä.) kann später ergänzt werden.
