# Landing Page

Einseitige Landing Page (One-Pager). Umsetzung erfolgt durch einen Coding-Agent.

## Steuerungs-Dokumente (zuerst lesen)
- **[Projekt.md](Projekt.md)** – roter Faden: Ziel, Zielgruppe, Sektionen, offene Entscheidungen.
- **[Design.md](Design.md)** – Design-Vorgaben: Farben, Typografie, Layout, Komponenten.

## Struktur
```
.
├─ index.html            # Einstiegspunkt (Platzhalter)
├─ Projekt.md            # Projekt-Steuerung
├─ Design.md             # Design-Vorgaben
├─ README.md             # diese Datei
├─ src/
│  ├─ css/styles.css     # Styles (Platzhalter)
│  └─ js/main.js         # Skripte (Platzhalter)
├─ content/
│  └─ texte.md           # Seitentexte, vom Code getrennt
└─ assets/
   ├─ images/            # Bilder (inkl. Logo)
   └─ fonts/             # Schriftarten
```

## Status
Grundgerüst steht. Es ist noch **kein** Framework-/Seiten-Code vorhanden – nur Struktur und Platzhalter.
